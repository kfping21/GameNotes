五、后端接口清单（摘要：按 Controller）
- 公共说明：所有接口返回均为 R 包装，分页接口通常接收 body 为 Map 类型，包含 page / pagesize 等。

1) `/api/youxi` (YouxiController)
- GET  /api/youxi/selectAll
- POST /api/youxi/selectPages  (body: Map)
- GET  /api/youxi/findById?id=INT
- GET  /api/youxi/categories
- POST /api/youxi/update  (body: Youxi)
- POST /api/youxi/insert  (body: Youxi)
- POST /api/youxi/delete  (body: List<Integer>)

2) `/api/topic` (TopicController)
- POST /api/topic/categories  (body optional)
- GET  /api/topic/findById?id=INT
- POST /api/topic/detail (body: {id, page?, pagesize?})
- POST /api/topic/notes (body: Map)
- POST /api/topic/discussion/list (body)
- POST /api/topic/discussion/create (body: {topicId, content, createdBy?})

3) `/api/yonghu` (YonghuController)
- GET  /api/yonghu/selectAll
- POST /api/yonghu/selectPages (body)
- GET  /api/yonghu/findById?id=INT
- POST /api/yonghu/update (body: Yonghu)
- POST /api/yonghu/insert (body)
- POST /api/yonghu/delete (body)
- POST /api/yonghu/detailWeb (body: {id})  -- 会执行访问数自增

4) `/api/user` (UserController)
- POST /api/user/login (body: LoginPojo)
- POST /api/user/editPassword (body: PasswordPojo)
- GET  /api/user/tokenLogin?token=...
- POST /api/user/logout
- POST /api/user/query (body)
- POST /api/user/select (body)

5) `/api/topic/chat` (TopicChatController)
- GET  /api/topic/chat/rooms
- POST /api/topic/chat/rooms/create (body: TopicChatRoom)
- POST /api/topic/chat/messages/paged (body: {roomId, page, pagesize})
- GET  /api/topic/chat/messages?roomId=...
- POST /api/topic/chat/send (body: {roomId, senderId, content})

6) 其它 CRUD 控制器（tongzhi, sixin, siliao, shoucang, pinglun, pinglunhuifu, lunbotu, dianzan, guanzhu）
- 标准 CRUD：GET /selectAll, POST /selectPages, GET /findById, POST /update, POST /insert, POST /delete
- 业务特殊接口示例：/api/pinglun/getdianzan, /api/guanzhu/isFollow 等

7) `/api/upload` (UploadController)
- POST /api/upload/save (multipart: field name = fujian) — 文件上传

8) `/api/order` (OrderController)
- POST /api/order/createFromCart
- GET  /api/order/detail?id=...
- GET  /api/order/list

9) `/api/mall` (MallController)
- GET  /api/mall/products?gameId=&categoryId=&keyword=&page=&size=
- GET  /api/mall/products/{id}
